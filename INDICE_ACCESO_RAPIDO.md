# 📚 ÍNDICE Y ACCESO RÁPIDO

## 🎯 ¿POR DÓNDE EMPIEZO?

### 1️⃣ Si es tu PRIMERA VEZ
```
1. Lee: README.md (2 min)
2. Lee: GUIA_USO.md - Sección "Inicio Rápido" (5 min)
3. Sigue: docs/INSTALACION.md (10 min)
4. ¡Listo!
```

### 2️⃣ Si quieres CONSTRUIR el sistema
```
1. Elige versión:
   - ¿Con macros (botones bonitos)? → ESTRUCTURA_VBA.txt
   - ¿Sin macros (simple)? → ESTRUCTURA_FORMULAS.txt

2. Sigue las instrucciones paso a paso

3. Copia/pega las tablas y fórmulas indicadas

4. Guarda y ¡usa!
```

### 3️⃣ Si necesitas EJEMPLOS de uso
```
1. Lee: EJEMPLOS_PRACTICOS.md
2. Busca tu caso (Nuevo huésped, Artículo dañado, etc)
3. Sigue el proceso descrito
4. Adapta a tu situación
```

### 4️⃣ Si hay un PROBLEMA
```
1. Consulta: GUIA_USO.md → Troubleshooting
2. Consulta: docs/INSTALACION.md → Solución de Problemas
3. Si persiste: Abre Issue en GitHub
```

## 🆘 RESOLVER PROBLEMAS

**"El archivo no se abre"**
- docs/INSTALACION.md → Solución de Problemas → "No se puede abrir"

**"Las macros no funcionan"**
- docs/INSTALACION.md → Solución de Problemas → "Macros deshabilitadas"
- docs/INSTALACION.md → Paso 3: Habilitar macros

**"Veo #REF! en las fórmulas"**
- GUIA_USO.md → Troubleshooting → "#REF!"
- Usa versión con Fórmulas como alternativa

**"Datos no se guardan"**
- GUIA_USO.md → Troubleshooting → "No guarda cambios"
- Verifica permisos de la carpeta

**"El sistema está lento"**
- GUIA_USO.md → Troubleshooting → "Archivo muy lento"
- Aumenta RAM o archiva datos antiguos
